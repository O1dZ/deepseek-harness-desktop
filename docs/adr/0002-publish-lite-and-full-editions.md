# Publish Lite and Full editions

DeepSeek Harness Desktop will ship two synchronized editions from every GitHub release: a Lite Edition that reuses development runtimes already on the computer, and a Full Edition that carries everything needed for immediate use. Both editions expose the official Harness UI and the same user data; accepting two runtime-delivery paths and a larger release matrix preserves a genuinely small download for technical users without weakening the click-to-run experience for everyone else.
